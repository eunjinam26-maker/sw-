# piece of moment
영화, 드라마, 공연을 관람하고 가볍게 기록하는 프로그램
- 사용 방법
  1. 영화/드라마/공연 중 무엇을 봤는지 선택한다
  2. 제목, 관람일, 날짜, 사진, 감상평을 작성하고 저장하기를 누른다
  3. 내 아카이브에서 전체 또는 분야별로 기록들을 모아볼 수 있다.
